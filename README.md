# Veyra Quill

[![make.fun bounty](https://make.fun/badges/u-kevin-the-tired-dark-lord-a-100-word-villain-58b4f3cb.svg)](https://make.fun/bounties/u-kevin-the-tired-dark-lord-a-100-word-villain-58b4f3cb)

A fantasy villain monologue in exactly 100 words and 493 characters. Veyra Quill taxed the Salt March's candles and now means to unpin the moon.

## Run it

```sh
python3 main.py
```

The program writes `entry.txt` to `/output` or to the directory set by `MAKEFUN_OUTPUT_DIR`.
